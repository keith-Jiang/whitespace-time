# 留白 · Whitespace

> A weekly board for the AI era — protect your deep work hours, stop being fragmented by AI.
>
> AI 时代的周视图时间管理看板：以深度时间为核心指标，把「等待 AI」显式化，用属性代替清单。

中文名「留白」取自中国画——空白处皆成妙境；英文名 Whitespace 自带双关：像代码里的空白字符，不可见，但不可少。

纯前端单页应用，无构建、无依赖、无后端。打开 `index.html` 即用，数据存在浏览器 localStorage。

## 为什么做这个

AI 时代的时间管理有三个新问题，传统 todo 工具都没有回答：

**1. 最稀缺的不是时间，是连续的注意力。**
AI 替你省下了大量执行时间，但人的价值越来越集中在深度思考上。所以这个工具的核心指标不是"今天完成了几件事"，而是"**今天深度工作了几小时**"。

**2. 碎片化的根源是你在被 AI 的节奏牵着走。**
AI 是异步工作的：你发出任务、等它跑、切去干别的、它一完成你又切回来——每次切换都有注意力残留。解法不是少用 AI，而是把"等待 AI 的任务"显式标记出来，**集中收割**产出，而不是随时被打断。

**3. 清单繁杂，是因为维度被拍平了。**
日/周/月是**周期**，四象限是**优先级**——它们是任务的两个正交属性，不是两种清单。用一维的文字列表去表达三维信息（周期 × 象限 × 时间），必然繁杂。正确做法：任务只录入一次，属性各自归位。

## 功能

- **周视图看板**：周一至周日 7 列，任务按周期规则自动展开到对应日期
  - `每日` 任务可限定范围：所有天 / 仅工作日 / 仅周末；`每周` 任务支持多选星期几；`每月` 任务在短月自动顺延到月末
  - 周期任务的完成状态按“出现日期”独立记录——今天勾掉，明天照常出现
  - 逾期回卷：过去没完成的一次性任务自动浮到今天并标「逾期」，不会静默消失
  - 一次性任务可直接拖拽到其它日期列
- **想法收集箱**：快捷键 `i` 唤出侧边抽屉，长期不紧急的念头随手收下，不随周切换丢失，可一键转为任务
- **深度时间一等公民**
  - 任务分「深度 / 碎片」两档，深度任务卡片视觉更重、永远置顶
  - 每天头部一条深度进度条（默认目标 4h/天），顶栏汇总本周深度时长
  - 顶栏「深度节奏」：7 个小刻度，哪天真的有深度时间一目了然
- **四象限作为属性而非布局**
  - 卡片左边框颜色编码象限：赭红（重要·紧急）、墨绿（重要·不紧急）、秋杏（紧急·不重要）、灰橄榄（不重要·不紧急）
  - 工具栏一键按象限 / 深浅 / 完成状态筛选
- **轻量 AI 泳道**
  - 任务可标记「⧖ 等待 AI」，卡片变虚线边框 + 呼吸蓝点
  - 顶栏徽标实时计数，点击筛出所有等 AI 的任务；点卡片上的标签表示"已收割产出"
- **零门槛**：快捷键 `n` 新建任务、`i` 收集箱、`←/→` 切换周，`Esc` 关闭弹窗；数据自动持久化到 localStorage，支持一键导出 / 导入备份；任务可加备注；每日深度目标可在设置中调整
- **中英双语**：顶栏一键切换界面语言（中 / EN），选择自动记忆

## 快速开始

```bash
git clone https://github.com/keith-Jiang/whitespace-time.git
cd whitespace-time

# 方式一：直接用浏览器打开 index.html
open index.html

# 方式二：起个本地服务器（推荐，字体加载更稳定）
python3 -m http.server 8642
# 然后访问 http://localhost:8642
```

首次打开自带 5 条示例任务，用于演示各属性如何归位，可随意删改。

## 项目结构

```
whitespace-time/
├── index.html   # 页面结构与任务编辑弹窗
├── style.css    # 视觉：暖纸底色 + 墨绿主色的编辑部质感
```

无框架、无构建步骤，原生 HTML/CSS/JS，约 1000 行。

## 数据模型

任务只有一条记录，渲染时按周期规则展开：

```js
{
  id: "...",
  title: "论文核心章节写作",
  depth: "deep" | "shallow",          // 深浅：深度任务计入深度时长
  cycle: "once" | "daily" | "weekly" | "monthly",
  date: "2026-07-30",                 // cycle=once 时生效
  weekday: 0,                         // cycle=weekly 时生效，0=周一
  monthDay: 1,                        // cycle=monthly 时生效
  quadrant: 1 | 2 | 3 | 4,            // 四象限
  duration: 120,                      // 预估分钟数
  waitingAI: false,                   // 是否等待 AI 产出
  completions: { "2026-07-30": true } // 按出现日期记录完成
}
```

数据存储于 `localStorage["whitespace.tasks.v1"]`，导出备份只需在控制台执行
`copy(localStorage.getItem("whitespace.tasks.v1"))`。
